# YOLO11m-StrongSORT-ONNX-Tracking
YOLO11m StrongSORT based MOT system for video surveillance and parking lot analysis. The project compares PyTorch (.pt) and ONNX (.onnx) deployments, evaluates tracking performance, generates annotated videos and tracking logs, and analyzes metrics such as FPS, latency, track lifetime, active tracks, and object identities in CPU-based environments.
